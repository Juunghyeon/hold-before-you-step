# Hold Before You Step

Project page for *Hold Before You Step: The Information Requirement of In-Place Push Recovery on Force-Sensorless Humanoids*
(J. Kim, J. Kim, S. Park).

- `index.html`: project page (videos in `assets/videos/`)
- `registrations/`: the registration of every test reported in the paper (criteria, sha256, result summaries, hashed hardware analysis code)
